# 📅 Monthly Release Calendar

This calendar outlines the release lifecycle for the **SQL Server DBA Operations Library**. Every month focuses on one core operational manual, progressing through planning, community drafting, technical review, and PDF release.

---

## 🔁 Standard Monthly Cadence

| Day of Month | Phase | Action |
| :--- | :--- | :--- |
| **Day 1** | **Kickoff** | Topic announcement & `Outline.md` published. |
| **Days 2–20** | **Collaboration** | Open contributions via PRs for `Draft.md` and `Scripts/`. |
| **Days 21–25** | **Review & Refinement** | Technical review, testing, and script validation. |
| **Day 25** | **Content Freeze** | No major structural PRs accepted; final copyediting only. |
| **Last Day** | **Publication** | Final PDF compiled, tagged in GitHub Releases, and published. |
